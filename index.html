Project abstract

Why this project exists.

Managing daily study activities is difficult when students juggle multiple subjects, topics, assignments and deadlines. They may forget topics, miss schedules, or struggle to monitor progress.

The Personal Study Planner organizes these activities in one system, with basic CRUD operations, task status management, search, filtering, scheduling and progress tracking, backed by a database and managed with Git and GitHub.

It aims to reduce the difficulty of managing study time, improve organization, and help students track their learning efficiently, while demonstrating frontend, backend and database development in one practical application.
